# AIEC Elevator OS — native Android app

**ALL INDIA ELEVATORS COMPANY — lead-to-handover work manager, rebuilt as a native Android app (Kotlin + Jetpack Compose) in मराठी · हिंदी · English.**

This repository is a fresh native rewrite of the web app in [UNLIT-GPT-HTML](https://github.com/prashantashwable-cmyk/UNLIT-GPT-HTML) (audited at commit `605575a`). It keeps that app's way of working: every action is a saved record, the same rules are checked on every phone, the next step is one big button, and everything works without internet. It adds a real Android UI, the system camera and GPS, SQLite storage, and no remote code.

## What is in v1.0.0
* 10 roles, 25 stages, 39 event types of the original with the same names and rules: lead → sales → quotation approval → agreement → payments confirmed by Finance → site prep & QC → material → 12 installation steps → final QC → handover → service tickets, plus SOS, people and business rules.
* Photos are taken with the camera only, stamped with time, GPS ± accuracy, person and job, and identified by SHA-256. Finger signatures.
* Tasks per person with two bars (work done, time used) and the escalation ladder in working days.
* Records files between company phones: each record is checked again and duplicates are skipped.
* 589 words in three languages (270 taken word-for-word from the original dictionary), 🔊 read-aloud, 4 colour themes.

**Not yet** (see `12_KNOWN_LIMITATIONS_AND_RISKS.md`): company server sync, record signing, chat, marketplace and partner companies, daily safety/check-in, statutory papers, purchase orders, AMC visits, notifications while closed, and the rest of the original's 212 event types. The APK in `dist/` is signed with an **evaluation key**; the production build needs the owner's key.

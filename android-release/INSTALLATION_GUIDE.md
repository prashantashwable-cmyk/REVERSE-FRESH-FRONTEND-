# Installation guide · इन्स्टॉल मार्गदर्शक · इंस्टॉल गाइड

File: `android-release/dist/AIEC-Elevator-OS-1.1.2-eval.apk` (signed evaluation build; check it against `SHA256SUMS.txt`). Android 8.0 or newer.

## English
1. Send the APK to the phone (WhatsApp to yourself, Google Drive or a cable).
2. Open it. Android asks to allow "Install unknown apps" for that app → allow → **Install**. If Play Protect warns: **More details → Install anyway**.
3. Open **AIEC Elevator OS** → choose मराठी / हिंदी / English.
4. To try it: **Practice mode** → tap a name → PIN **1111**. Nothing in practice is real, and it never mixes with company data.
5. Real company: **New company setup** (Head Quarter: company name, your name, a new PIN that is not 1111/1234). Then **People → Add a person** for each worker with their role and a PIN; tell them the PIN on a call.
   Each worker's phone shows a **phone code** on Me → Share data the first time they log in. Call them, check the code, and press **Approve** under People → Phones waiting for approval. Records from that phone are accepted by other company phones only after this.
6. Camera and location are asked the first time a photo or location is needed. If you said "no", allow them in Settings → Apps → AIEC Elevator OS → Permissions.
7. This evaluation build is a separate app from the old web/WebView app (`com.allindiaelevators.os`), so both can stay on the phone. They do **not** share data.

## मराठी
1. APK फाइल फोनवर पाठवा (स्वतःला WhatsApp, Google Drive किंवा केबल).
2. फाइल उघडा. "Install unknown apps" ला परवानगी द्या → **Install**. Play Protect ने इशारा दिल्यास: **More details → Install anyway**.
3. **AIEC एलिव्हेटर OS** उघडा → भाषा निवडा.
4. सरावासाठी: **सराव मोड** → नाव दाबा → PIN **1111**. सरावातील काहीही खरे नाही; कंपनीच्या माहितीत मिसळत नाही.
5. खरी कंपनी: **नवीन कंपनी सेटअप** (हेड क्वार्टर: कंपनीचे नाव, तुमचे नाव, नवीन PIN — 1111/1234 नको). मग **लोक → व्यक्ती जोडा** — प्रत्येकाची भूमिका आणि PIN; PIN फोनवर सांगा. प्रत्येक कर्मचाऱ्याच्या फोनचा **फोन कोड** (मी → डेटा शेअर) फोनवर जुळवून **लोक** स्क्रीनवर **मंजूर करा** दाबा.
6. कॅमेरा व लोकेशनची परवानगी पहिल्यांदा गरज लागल्यावरच विचारली जाते.

## हिंदी
1. APK फ़ाइल फ़ोन पर भेजें (ख़ुद को WhatsApp, Google Drive या केबल)।
2. फ़ाइल खोलें। "Install unknown apps" की अनुमति दें → **Install**। Play Protect चेतावनी दे तो: **More details → Install anyway**।
3. **AIEC एलिवेटर OS** खोलें → भाषा चुनें।
4. अभ्यास के लिए: **अभ्यास मोड** → नाम दबाएँ → PIN **1111**। अभ्यास में कुछ भी असली नहीं है; कंपनी के डेटा से नहीं मिलता।
5. असली कंपनी: **नई कंपनी सेटअप** (हेड क्वार्टर: कंपनी का नाम, अपना नाम, नया PIN — 1111/1234 नहीं)। फिर **लोग → व्यक्ति जोड़ें** — हर व्यक्ति की भूमिका और PIN; PIN फ़ोन पर बताएँ। हर कर्मचारी के फ़ोन का **फ़ोन कोड** (मैं → डेटा शेयर) फ़ोन पर मिलाकर **लोग** स्क्रीन पर **मंज़ूर करें** दबाएँ।
6. कैमरा और लोकेशन की अनुमति पहली बार ज़रूरत पड़ने पर ही माँगी जाती है।
